# Fast Track v1.0.0 - Initial Release 🎉

Welcome to the very first release of **Fast Track**! This release establishes the core foundation of our zero-friction expense tracker.

## 🌟 Highlights
- **Lightning Fast Input**: A custom on-screen keypad optimized for entering amounts quickly without standard Android soft-keyboard lag.
- **Local First Architecture**: Complete privacy and immediate data access thanks to Jetpack Room database local storage.
- **Dark Minimalist Aesthetic**: A beautiful dark monochromatic UI designed for functionality. The high contrast allows you to log expenses in seconds without visual clutter.

## 🚀 Features Added
- Main dashboard with real-time "Today's Total" accumulator.
- Swipe-to-delete functionality for the history list.
- Timestamp and dynamic grouping logic.
- R8/ProGuard fully enabled for minimal APK size and maximum performance.

## ⚡ Performance Optimizations
- Implemented `StateFlow` and Coroutines for smooth, asynchronous database operations, ensuring the main UI thread is never blocked.
- Bypassed system keyboard instantiation times to guarantee a "tap-to-type" delay of 0ms.
