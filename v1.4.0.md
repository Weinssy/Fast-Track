# Fast Track v1.4.0 - Custom Tags & Dynamic Database Update 🎉

We've listened to your feedback! The highly requested Custom Tags feature is finally here in v1.4.0.

## 🌟 Highlights
- **Dynamic Custom Tags**: You are no longer restricted to the default preset categories. You can now create your own custom categories (tags) directly from the main screen by tapping the new **"+ Tambah"** button. The new tag will seamlessly integrate into your fast tagging workflow.
- **Architectural Upgrade**: Under the hood, we've transitioned the tag list from a static hardcoded string array to a fully dynamic **Room Database** table, ensuring your custom tags are saved permanently and securely on your device.

## 🚀 Features & Changes
- Added a Material 3 dialog for creating new tags cleanly without displacing the main keypad UI.
- Implemented `MIGRATION_1_2` script to safely transition your existing database schema.
- Older legacy expenses that were tagged as `General` (from v1.0.0 days) are now automatically mapped to the unified `Umum` tag.
- Full backward compatibility is guaranteed. You will not lose any historical data when updating to this version.
